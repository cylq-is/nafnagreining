# Icelandic Hunspell dictionary

`is.dic` and `is.aff` are the Icelandic Hunspell dictionary from the
[hunspell-is](https://github.com/nifgraup/hunspell-is) project, copied unchanged from
[LibreOffice/dictionaries](https://github.com/LibreOffice/dictionaries/tree/master/is).
They are based on Icelandic Wiktionary (https://is.wiktionary.org).

Licence: [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/legalcode).

`tools/build_wordlist.py` expands them into `src/nafnagreining/data/is_words.txt.gz`.
